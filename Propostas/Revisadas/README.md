# Propostas Revisadas — Versus

Esta pasta contém versões textuais editáveis das propostas comerciais, criadas para servir como matriz antes da edição visual dos `.pptx`.

## Arquivos
- `Proposta_Matriz_Servicos_Pontuais_Revisada.md`
- `Proposta_Matriz_Performance_Hub_Revisada.md`

## Como usar
1. Validar copy, escopo e condições comerciais.
2. Escolher quais trechos entram em cada cliente.
3. Revisar preço, prazo, cases e evidências.
4. Só depois aplicar no PowerPoint.

## Guardrail
Não enviar estes arquivos diretamente ao cliente sem revisão humana e ajuste visual.
