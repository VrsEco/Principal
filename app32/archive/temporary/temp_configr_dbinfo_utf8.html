Onde encontrar os dados de acesso de Banco de Dados

13 de agosto de 2020

E aí, tudo bem?

O objetivo deste artigo é mostrar um passo a passo de como você pode encontrar os dados de acesso de um Banco de Dados através da nossa plataforma.

Vamos lá!

Passo 1

Acesse a área de login do seu painel.

Passo 2

Na aba lateral no canto esquerdo, vá até o menu e clique na opção “Websites”.

Passo 3

Na sua listagem de websites, localize e clique sobre o site que você deseja deseja encontrar os dados de Banco de Dados.

Passo 4

Na tela de detalhes do website, clique na aba Databases e, em seguida, sobre o Banco de Dados que você deseja descobrir as informações de acesso.

Passo 5

Na tela de detalhes do Banco de Dados, você tem acesso aos usuários do Banco e demais informações., como usuário e senha.

Nessa tela você já consegue visualizar dados importantes como o nome do Banco de Dados e o nome de usuário.

Caso você decida atualizar as informações do usuário do Banco de Dados, e ele seja utilizado por mais de uma aplicação, também será necessário modificar a senha na aplicação.

Tudo pronto!

Seguindo os 5 passos acima, você poderá encontrar os dados de acesso de Banco de Dados.
