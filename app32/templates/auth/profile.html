Instalação guiada de squads

Escolha onde você vai instalar, confirme qual versão do Sapiens será publicada e gere o código guiado para a IA fazer a configuração. O modo avançado fica disponível só quando necessário.

Passo a passo recomendado
  1. Escolha o cliente/CLI e a empresa padrão.
  2. Gere ou renove o token no final desta tela.
  3. Clique em Gerar código para IA, copie e cole no cliente escolhido.
  4. Peça para a IA criar a entrada com o nome visível do Sapiens correspondente.

Como a instalação funciona
A instalação publica uma entrada do Sapiens no seu cliente/CLI. Essa entrada começa pelo agente coordenador do squad e usa o harness inicial resolvido automaticamente pelo APP32. Depois disso, o próprio Sapiens pode rotear a conversa para especialistas internos quando necessário.
A experiência principal é gerar o código guiado e colar no cliente/CLI escolhido. O conteúdo já explica o nome visível do Sapiens, o agente coordenador e o uso do harness inicial. Use o modo avançado apenas quando necessário.
