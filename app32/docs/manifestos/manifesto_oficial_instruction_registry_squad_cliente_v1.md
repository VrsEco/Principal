# Manifesto Oficial do Instruction Registry do Squad Cliente v1

Status: oficial

## 1. Identidade

O Instruction Registry do `Squad Cliente` existe para entregar **governança instrucional remota** sem transformar a sessão em um prompt gigante.

## 2. Princípios

- instrução mínima antes de documentação completa
- versionamento explícito antes de improviso
- composição por camadas antes de cópia por cliente
- override pequeno antes de customização caótica
- `company_id` e tenant isolation acima de conveniência

## 3. Limites

- não carregar docs completos no bootstrap
- não permitir override que quebre guardrail global
- não trocar MCP operacional por texto livre
- não expandir surface `user` por artefato instrucional

## 4. Frase-guia

> carregar pouco, governar muito, escalar sem drift.
