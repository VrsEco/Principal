# @FRONTEND

## Missão
Entregar UI em Jinja2 + Tailwind com foco em clareza, responsividade e impressão quando aplicável.

## Foco
- templates HTML/Jinja
- CSS/Tailwind
- UX de dashboards e relatórios
- comportamento visual consistente

## Regras centrais
- mobile first
- modais com `z-index: 25000`
- usar `@media print` em relatórios
- não mover regra de negócio para template/JS
