# Catálogo Vendor / Legado

Este diretório contém o catálogo externo/legado de skills trazido para o repositório, mas **fora do caminho ativo padrão** do Gestão Versus.

## Regra
Não carregar este diretório por padrão em tarefas do projeto.

## Usar somente quando
- houver pedido explícito para inspecionar o catálogo legado
- for necessário reaproveitar ou importar uma skill externa
- houver manutenção específica do pacote legado

## Núcleo ativo do projeto
Use preferencialmente:
- `C:\GestaoVersus\app32\app32\.agent\skills\`
- `C:\GestaoVersus\app32\app32\.agent\router\`
- `C:\GestaoVersus\app32\app32\.agent\agents\`
- `C:\GestaoVersus\app32\app32\.agent\references\`
