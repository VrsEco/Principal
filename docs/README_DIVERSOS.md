# 📁 docs/diversos

Este diretório contém arquivos antigos, scripts temporários e documentação histórica que não são mais necessários para o funcionamento do sistema, mas são mantidos para referência.

## 📂 Estrutura

```
docs/diversos/
├── scripts_antigos/
│   ├── migracoes/           # Scripts de migração já executados
│   ├── debug_testes/        # Scripts de debug e teste
│   ├── verificacao/         # Scripts de verificação (check/verify)
│   ├── temporarios/         # Scripts temporários (temp/tmp)
│   ├── setup_config/        # Scripts de setup/configuração inicial
│   ├── manutencao/          # Scripts de manutenção/correção antiga
│   ├── criacao_tabelas/     # Scripts de criação de tabelas já executados
│   └── relatorios_backup/   # Scripts de relatórios/backup antigos
├── documentacao_antiga/     # Documentação histórica (.md)
└── scripts_bat_antigos/     # Scripts batch (.bat) antigos
```

## ⚠️ Importante

- **NÃO** usar estes arquivos diretamente
- **NÃO** mover de volta para a raiz sem revisar
- Manter apenas para referência histórica
- Se precisar usar algo, copiar e adaptar
